# Triage labels

Use these labels as the `Status:` value in local issue files under `.scratch/`.

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | An agent can implement the specified issue. |
| `ready-for-human` | A person needs to implement the issue. |
| `wontfix` | The project will not pursue the issue. |
